# WA Hub 3

مشروع واحد يبني **Windows + Linux + Android**.

## كيف يعمل
1. **تسجّل رقمك مرة واحدة** في بداية التطبيق (رمز ربط)، وتُحفظ الجلسة.
2. تختار الوضع، ويمكنك «تذكّر الاختيار»:
   - **مشاهدة (غرف):** الأجزاء التي تصل في الشات تُحفظ في «غرف» دائمة داخل أقسام (غير مصنّف + أقسام تنشئها بنفسك + ⭐ المفضلة). تدخل الغرفة فتُشغَّل أجزاؤها متتابعة كفيديو واحد، مع حفظ موضع توقفك، وبلا تشغيل تلقائي وبلا دمج. الغرفة غير المفضلة التي تضغط فيها «✓ أكملت الغرفة» تُحذف كلها عند فحص الدخول بعد مرور 10 ساعات؛ المفضلة لا تُحذف أبداً إلا بيدك.
   - **تحميل:** يحمّل الملفات التي تصل إلى الشات فوراً كما هي (لا يوجد دمج في التطبيق — الدمج يتم خارجياً إن أردته).
3. تبدّل بين الوضعين في أي وقت من «🔀 تغيير الوضع» في الإعدادات، والرقم نفسه (اتصال واتساب واحد) يعمل في الاثنين.

### أوامر الشات (وضع المشاهدة)
اكتبها في محادثتك (تبدأ بـ `!` أو `/`): `!pause` `!play` `!next` `!fs` `!speed 1.25` `!vol 50` `!status`
أو بالعربية: `!ايقاف` `!تشغيل` `!تخطي` `!سرعة 1.25` `!صوت 50`.

## البنية
| المجلد | المحتوى |
|---|---|
| `desktop/` | تطبيق Electron لويندوز ولينكس (يتضمن mpv على ويندوز) |
| `android/` | تطبيق أندرويد (Kotlin + Compose + محرك Node المضمّن) |
| `.github/workflows/build.yml` | بناء الثلاثة معاً |

## البناء
ادفع المشروع إلى GitHub، فيبدأ **Build WA Hub 3** تلقائياً ويُنتج:

| الملف | المنصة |
|---|---|
| `WA-Hub-3-x.x.x-portable.exe` | Windows (بدون تثبيت) |
| `WA-Hub-3-x.x.x.AppImage` و `.tar.gz` | Linux |
| `WA-Hub-3-android.apk` | Android |

تجدها في: **Actions ← آخر تشغيل ← Artifacts**.
ولتنشئ صفحة تنزيل دائمة: `git tag v1.0 && git push origin v1.0` فتُرفق الملفات الثلاثة في **Releases**.

## التشغيل
- **Windows:** شغّل الـ exe مباشرة.
- **Linux:** `sudo apt install mpv` ثم `chmod +x WA-Hub-3-*.AppImage && ./WA-Hub-3-*.AppImage` (إن أغلق فوراً: `--no-sandbox`).
- **Android:** ثبّت الـ APK (اسمح بالتثبيت من مصدر غير معروف) واسمح بالإشعارات.

> Baileys مكتبة غير رسمية وقد يحظر واتساب الحساب؛ استخدم رقماً لا تخسر منه.
